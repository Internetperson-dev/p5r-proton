# p5r-proton


A updated version of Proton 7 before Persona 5 Royal performance regressions.

See:

- https://github.com/ValveSoftware/Proton/issues/8687#issuecomment-4687001179
- https://github.com/ValveSoftware/Proton/issues/8617#issuecomment-2869390791


Patched with the latest version of DXVK and vkd3d for Persona 5 Royal, [upscaler mods](https://www.patreon.com/huutaiii/posts/p5r-enhanced-fsr-157194073).

[Reloaded-II Proton-GE](https://github.com/GloriousEggroll/proton-ge-custom/issues/873) patch is also applied.
